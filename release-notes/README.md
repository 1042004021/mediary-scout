# 发布说明

每个发布标签 `vYYYY.MM.DD`（同一天第二次发布起 `vYYYY.MM.DD.2`、`.3`…）对应这里一个同名 `.md` 文件，设置页「更新」tab 会显示它。

格式：每条一行，以「新增」「改进」「修复」开头，后面一句用户能看懂的话。不写 PR 号、函数名、内部术语。

    - 修复 巡检不会在一次运行里把同一个资源包转存两次
    - 新增 光鸭网盘支持转存别人分享的链接
    - 改进 转存中途失败留下的临时文件夹，系统会自己收拾干净

只有在作者自己的实例上验证过的 main 提交才打标签。流程：写好本文件 → 合并到 main → 在该提交上 `git tag vYYYY.MM.DD && git push origin vYYYY.MM.DD`。
